# Zomato Data Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on Zomato restaurant data to uncover insights about restaurant ratings, online ordering, restaurant costs, and customer preferences.

## Objectives
- Analyze restaurant ratings
- Explore online ordering trends
- Study restaurant cost patterns
- Identify popular cuisines
- Understand customer behavior

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
Zomato Restaurant Dataset

## Key Analysis Performed
- Data Cleaning
- Missing Value Handling
- Cost Analysis
- Rating Analysis
- Restaurant Distribution Analysis
- Data Visualization
